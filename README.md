# 🐾 Landing Page - Clínica Veterinária Kikão

Landing page profissional e responsiva desenvolvida para a **Clínica Veterinária Kikão**, um centro completo de cuidado animal que inclui clínica, pet shop e hotelzinho.

**[➡️ Acesse a demonstração ao vivo](https://mayasrl.github.io/lp-kikao/)**

---

## 📋 Sobre o Projeto

Este projeto consiste na criação de uma landing page moderna e completa, projetada para apresentar os serviços da Clínica Veterinária Kikão, atrair novos clientes e simplificar o processo de agendamento de consultas através da integração direta com o WhatsApp.

O layout é totalmente responsivo, garantindo uma experiência de usuário consistente e agradável em desktops, tablets e smartphones.

---

## ✨ Funcionalidades Principais

O projeto foi desenvolvido com foco na experiência do usuário e otimização para motores de busca (SEO).

- **Design Totalmente Responsivo**: Adapta-se perfeitamente a qualquer tamanho de tela.
- **Integração com WhatsApp**: Botão de contato flutuante e links diretos para agendamento.
- **Menu de Navegação Intuitivo**: Menu fixo no topo e menu hambúrguer para dispositivos móveis.
- **SEO Avançado**: Implementação de meta tags, `robots.txt`, `sitemap.xml` e dados estruturados (Schema.org) para melhor indexação no Google.
- **Otimização de Performance**: Preload de recursos críticos (CSS, imagens) para um carregamento mais rápido.
- **Biblioteca de Ícones SVG**: Ícones personalizados e otimizados para um design coeso e leve.
- **Interatividade com JavaScript**: Animações suaves, scroll suave e funcionalidades dinâmicas.
- **Compatibilidade com PWA**: `manifest.json` para permitir que o site seja "instalado" em dispositivos móveis.

## 📁 Estrutura de Arquivos

A estrutura de pastas foi organizada para garantir clareza e manutenibilidade.

```
lk-kikao/
│
├── css/                  # Arquivos de estilização (style.css)
├── icons/                # Biblioteca de ícones SVG (icons.svg)
├── images/               # Imagens e assets visuais (logos, favicons)
├── js/                   # Scripts JavaScript (script.js)
├── .htaccess             # Configurações do servidor Apache
├── index.html            # Arquivo HTML principal
├── manifest.json         # Manifest para Progressive Web App (PWA)
├── README.md             # Documentação do projeto
├── robots.txt            # Instruções para crawlers de busca
└── sitemap.xml           # Mapa do site para SEO
```
